# Rebuild Plugin - אריזת הסוכן מחדש

## מה זה עושה (במילים פשוטות)

כשמשנים משהו בסוכן - מסמך ידע, סקיל, או האופי שלו - משנים אותו ב**תיקיית המקור** (המקום שבו הקבצים האמיתיים של הסוכן גרים, בתוך הריפו). אבל הגרסה ש**מותקנת** ב-Claude עדיין לא מכירה את השינוי - היא צילום ישן.

**Rebuild = אריזה מחדש.** הסקיל הזה לוקח את תיקיית המקור המעודכנת, אורז אותה מחדש לקובץ פלאגין אחד (`.plugin`), ושם אותו בתיקיית `plugins-to-install/` שבשורש הריפו. משם המשתמש מתקין אותו מחדש - ועכשיו הגרסה המותקנת מעודכנת.

> התהליך במשפט: **מתקנים את תיקיית המקור ← עושים rebuild ← הפלאגין נכנס ל-`plugins-to-install/` ← מתקינים מחדש.**

## מתי מפעילים

אחרי כל שינוי בסוכן. "שמרתי" זה לא "הסוכן המותקן יודע" - רק אחרי rebuild + התקנה מחדש.

## השלבים שאני מבצע

1. **מזהה את הסוכן לארוז.** מחפש תיקיות סוכן ב-`agents/ready/` וב-`agents/in-progress/` (כל תת-תיקייה שיש בה `.claude-plugin/plugin.json`). אם יש כמה - שואל את המשתמש איזה סוכן. אם יש אחד - ממשיך איתו ומודיע איזה.

2. **מוודא מקור תקין.** בודק שבתיקיית הסוכן יש `.claude-plugin/plugin.json`. אם אין - עוצר ומסביר למשתמש שזו כנראה לא תיקיית סוכן תקינה, בלי לנחש.

3. **מעלה את מספר הגרסה** ב-`plugin.json` (הספרה האחרונה ב-`version`, למשל `0.1.0` ← `0.1.1`). זה מה שגורם ל-Claude לזהות שזו גרסה חדשה בהתקנה.

4. **מוודא שקיימת `plugins-to-install/`** בשורש הריפו. אם לא קיימת - יוצר אותה (זה צפוי אצל מי שסיים את ההכנה לפני שהתיקייה נכנסה למבנה - פשוט יוצרים וממשיכים).

5. **אורז** את תיקיית הסוכן לקובץ `.plugin` בתוך `plugins-to-install/`:
   ```bash
   cd <נתיב-תיקיית-הסוכן>
   zip -r <שורש-הריפו>/plugins-to-install/<שם-הסוכן>.plugin . -x "*.DS_Store" -x "*/.git/*"
   ```

6. **מדווח למשתמש:** נתיב הקובץ שנוצר, גודלו, והגרסה החדשה.

## מה המשתמש עושה אחרי (אני מנחה אותו)

> "הפלאגין המעודכן מחכה ב-`plugins-to-install/<שם>.plugin`. עכשיו:
> 1. גררו את הקובץ לתוך חלון Claude Desktop (או: הגדרות ← פלאגינים ← התקנה מקובץ).
> 2. סגרו את Claude לגמרי (Force Quit) ופתחו מחדש.
> 3. פתחו שיחה חדשה עם הסוכן ובדקו שהוא מכיר את השינוי החדש."

## כללים

- **לא ממציא נתיבים.** אם לא מצאתי את תיקיית הסוכן או את `plugin.json` - עוצר ושואל את המשתמש, לא מנחש.
- **לא מוחק כלום.** רק אורז ומעתיק. תיקיית המקור נשארת נגיעה.
- **מקור אחד.** מתקנים תמיד בתיקיית המקור (`agents/ready/<שם>/` או `agents/in-progress/<שם>-dev/`), לעולם לא בגרסה המותקנת.
- שפה למשתמש: עברית פשוטה. נתיבים ושמות קבצים: אנגלית.
