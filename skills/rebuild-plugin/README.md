# 🔄 Rebuild Plugin

אריזת סוכן מחדש לקובץ פלאגין (`.plugin`), התקנתו, והחלפת הגרסה הישנה המותקנת - כך שנשארת רק גרסה אחת מעודכנת.

## מה זה נותן לך

כשאתם משנים משהו בסוכן (מסמך ידע, סקיל, אופי) - השינוי יושב בתיקיית המקור, אבל הגרסה המותקנת ב-Claude עדיין לא מכירה אותו. הסקיל אורז את תיקיית הסוכן המעודכנת, **מתקין אותה במקום הישנה, ומוחק את הישנה**. אין כפילות ואין מה למחוק - נשארת גרסה אחת, מעודכנת.

**התהליך:** מתקנים את תיקיית המקור ← אומרים "rebuild" ← הפלאגין נארז, מותקן, והישן מוחלף ← פותחים שיחה חדשה.

## עובד בכל מחשב

הסקיל מתאים את הפקודות למערכת ההפעלה שלכם (Mac / Windows / Linux) - לפי מה שרשום ב-`CLAUDE.md` של הריפו. אין צורך בשום התאמה ידנית.

## מתי להשתמש

אחרי כל שינוי בסוכן. אומרים "rebuild" או "תארוז את הסוכן מחדש".

## התקנה (פעם אחת)

1. הורידו את ה-ZIP וחלצו - תתקבל תיקייה בשם `rebuild-plugin`.
2. שלחו לקלוד את הנתיב לתיקייה ובקשו ממנו להתקין את הסקיל.
3. פתחו שיחה חדשה מחוברת לריפו של הסוכנים שלכם, ואמרו "rebuild".

## מדריך מלא

המדריך המלא בדאטהבייס המדריכים: "איך בונים פלאגין מחדש - rebuild-plugin".
