# 🔄 Rebuild Plugin

אריזת סוכן מחדש לקובץ פלאגין (`.plugin`), **התקנתו האוטומטית והחלפת הגרסה הישנה** - עם בדיקות בטיחות שמונעות היעלמות שקטה של סוכנים.

## מה זה נותן לך

כשאתם משנים משהו בסוכן (מסמך ידע, סקיל, אופי) - השינוי יושב בתיקיית המקור, אבל הגרסה המותקנת ב-Claude עדיין לא מכירה אותו. הסקיל אורז את תיקיית הסוכן המעודכנת לקובץ פלאגין אחד, **מתקין אותו במקום הגרסה הישנה ומוחק את הישנה** - כך שנשארת רק גרסה אחת מעודכנת. **אין מה למחוק ואין כפילות.**

**התהליך:** מתקנים את תיקיית המקור ← אומרים "rebuild" ← הסקיל אורז, מתקין, ומחליף את הישן ← פותחים שיחה חדשה.

## בטוח בכל מחשב

הסקיל מתאים את הפקודות למערכת ההפעלה שלכם (Mac / Windows / Linux), אורז נכון גם ב-Windows, ובודק ארבעה דברים לפני האריזה כדי שהסוכן לא ייעלם בשקט (שורש הפלאגין, מבנה תקין של קובץ ה-SKILL, שאין BOM, וסכמת plugin.json תקינה). אחרי ההתקנה הוא **רושם את הפלאגין במלואו** - כך שהוא באמת עולה ולא רק יושב על הדיסק.

לפני שהוא מחליף את הגרסה המותקנת - הוא **מגבה אותה**, ומאמת אחרי ההתקנה. אם משהו נכשל, הוא **משחזר את הישנה לבד** ומנחה התקנה ידנית. בסביבה שאינה Claude Desktop, הוא פשוט אורז ומנחה התקנה ידנית.

## מתי להשתמש

אחרי כל שינוי בסוכן. אומרים "rebuild" או "תארוז את הסוכן מחדש".

## התקנה (פעם אחת)

1. הורידו את ה-ZIP וחלצו - תתקבל תיקייה בשם `rebuild-plugin`.
2. שלחו לקלוד את הנתיב לתיקייה ובקשו ממנו להתקין את הסקיל.
3. פתחו שיחה חדשה מחוברת לריפו של הסוכנים שלכם, ואמרו "rebuild".

## מדריך מלא

המדריך המלא בדאטהבייס המדריכים: "איך בונים פלאגין מחדש - rebuild-plugin".
