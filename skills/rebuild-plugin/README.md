# 🔄 Rebuild Plugin

אריזת סוכן מחדש לקובץ פלאגין (`.plugin`) והכנתו להתקנה מחדש.

## מה זה נותן לך

כשאתם משנים משהו בסוכן (מסמך ידע, סקיל, אופי) - השינוי יושב בתיקיית המקור, אבל הגרסה המותקנת ב-Claude עדיין לא מכירה אותו. הסקיל הזה אורז את תיקיית הסוכן המעודכנת לקובץ פלאגין אחד ושם אותו ב-`plugins-to-install/` - משם מתקינים מחדש, והסוכן מעודכן.

**התהליך:** מתקנים את תיקיית המקור ← עושים rebuild ← הפלאגין נכנס ל-`plugins-to-install/` ← מתקינים מחדש.

## מתי להשתמש

אחרי כל שינוי בסוכן. אומרים "rebuild" או "תארוז את הסוכן מחדש".

## התקנה

1. הורידו את ה-ZIP וחלצו - תתקבל תיקייה בשם `rebuild-plugin`.
2. שלחו לקלוד את הנתיב לתיקייה ובקשו ממנו להתקין את הסקיל.
3. פתחו שיחה חדשה מחוברת לריפו של הסוכנים שלכם, ואמרו "rebuild".

## מדריך מלא

המדריך המלא בדאטהבייס המדריכים: "איך בונים פלאגין מחדש - rebuild-plugin".
