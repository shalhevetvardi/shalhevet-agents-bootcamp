# 🔄 Rebuild Plugin

אריזת סוכן מחדש לקובץ פלאגין (`.plugin`) והתקנתו מחדש בקלוד - עם בדיקות בטיחות שמונעות היעלמות שקטה של סוכנים.

## מה זה נותן לך

כשאתם משנים משהו בסוכן (מסמך ידע, סקיל, אופי) - השינוי יושב בתיקיית המקור, אבל הגרסה המותקנת ב-Claude עדיין לא מכירה אותו. הסקיל אורז את תיקיית הסוכן המעודכנת לקובץ פלאגין אחד ושם אותו ב-`plugins-to-install/`. משם **אתם מתקינים אותו מחדש דרך קלוד** - וההתקנה מחדש מעדכנת את הגרסה הקיימת. **אין מה למחוק ואין כפילות.**

**התהליך:** מתקנים את תיקיית המקור ← אומרים "rebuild" ← הפלאגין נכנס ל-`plugins-to-install/` ← מתקינים מחדש בקלוד.

## בטוח בכל מחשב

הסקיל מתאים את הפקודות למערכת ההפעלה שלכם (Mac / Windows / Linux), אורז נכון גם ב-Windows, ובודק שני דברים לפני האריזה כדי שהסוכן לא ייעלם בשקט (מבנה תקין של קובץ ה-SKILL, ושאין BOM בקובץ ה-plugin.json). **הסקיל לא נוגע בקבצים הפנימיים של קלוד** - ההתקנה תמיד דרך הממשק.

## מתי להשתמש

אחרי כל שינוי בסוכן. אומרים "rebuild" או "תארוז את הסוכן מחדש".

## התקנה (פעם אחת)

1. הורידו את ה-ZIP וחלצו - תתקבל תיקייה בשם `rebuild-plugin`.
2. שלחו לקלוד את הנתיב לתיקייה ובקשו ממנו להתקין את הסקיל.
3. פתחו שיחה חדשה מחוברת לריפו של הסוכנים שלכם, ואמרו "rebuild".

## מדריך מלא

המדריך המלא בדאטהבייס המדריכים: "איך בונים פלאגין מחדש - rebuild-plugin".
