# הוספת סקיל לספריית הסקילים — צ'קליסט פרסום

ספרייה זו מפיצה סקילים לתלמידי "טירונות סוכנים". כל סקיל חי בשני פנים: **קובץ ב-repo** (להורדה) ו**כרטיס בנושן** (לעיון). פרסום חלקי = סקיל שמתועד אבל לא זמין להורדה, או זמין אבל לא מופיע בספרייה. שתי התקלות קרו בעבר — הצ'קליסט הזה מונע אותן.

## 5 התחנות — כולן, אחרת הפרסום חלקי

1. **קובץ ב-repo** — `skills/<name>/SKILL.md`, מהמקור הנקי בלבד (לא מ-worktree לא-ממוזג).
2. **ZIP להורדה** — `skills/<name>.zip` שמכיל את התיקייה `<name>/`:
   ```bash
   cd skills && zip -r <name>.zip <name>/ -x "*.DS_Store"
   ```
   הקישור הישיר שלוחצים עליו ויורד: `https://github.com/shalhevetvardi/shalhevet-agents-bootcamp/raw/main/skills/<name>.zip`
   חובה לאמת אחרי push: `curl -sIL <url>` → `HTTP 200` + `content-type: application/zip`.
3. **כרטיס בנושן** — רשומה ב-database "📦 ספריית סקילים — טירונות סוכנים" (`data_source: e30667f1-6582-4ffe-a1f7-5a689968b2f1`). שדות: שם הסקיל / מה הוא נותן לך / מתי תשתמש בו / קטגוריה / סטטוס. בגוף הכרטיס: callout הורדה + 3 צעדי התקנה. **לא** להדביק את כל ה-SKILL.md כ-copy-paste — ה-ZIP מחליף את הנוסח הארוך.
4. **VO (המשרד הווירטואלי)** — `add_skill` (או `update_skill` אם קיים) עם `status` ו-`github_path`; edge `owns` מהישות knowledge_item "ספריית הסקילים הגנרית"; `add_history` שמתעד את הפרסום. ישות בלי edge = יתומה.
5. **README** — לעדכן ב-`skills/README.md` את מונה הסקילים ואת הקטגוריה.

## אם לסקיל יש מדריך טירונות נלווה (במאגר המדריכים)

לקשר דו-כיוונית: המדריך → קישור ההורדה של הסקיל; הכרטיס בנושן → קישור למדריך. כך אין כפילות "נוסח + הורדה", והתלמיד מגיע מכל כיוון.
דוגמה: `night-run-orchestrator` ↔ מדריך "ריצת לילה — לשלוח עבודה לרוץ בזמן שאתם ישנים".

## עדכון סקיל קיים

לבנות מחדש את ה-ZIP, לדחוף, ולהוסיף `add_history` ב-VO. הכרטיס בנושן והקישור לא משתנים (אותו URL) — רק התוכן מאחוריהם מתעדכן.
