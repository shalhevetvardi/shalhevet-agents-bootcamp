# לא לחפור - הוראות לניסוי

זו גרסת ניסיון של שלהבת ורדי מאִימפּרוּב. המטרה היא הסברים שאפשר להבין ולהמשיך מהם, בלי לצמצם את החקירה, הביצוע והבדיקות.

## איך מנסים

1. חלצו את קובץ ה-ZIP המצורף. בתוך התיקייה work-with-clarity נמצאים SKILL.md ותיקיית references. שמרו אותם יחד.
2. פתחו שיחה ב-Claude Code בתיקיית הפרויקט שלכם. אין צורך להחליף את קובץ הכללים או להתקין הפעלה קבועה.
3. גררו לשיחה את הקובץ SKILL.md שחילצתם כדי לציין את מיקומו. אם הגרירה אינה זמינה, העתיקו את הנתיב המלא שלו והדביקו בשיחה.
4. כתבו את הבקשה הבאה, ואחריה משימה אמיתית שלכם:

```text
קרא את קובץ SKILL.md שבנתיב שצירפתי. זה הסקיל ״לא לחפור״.
השתמש בהנחיותיו בשיחה הזאת כדי להסביר לי בצורה ברורה ועם ההקשר שאני צריך.
שמור על הוראות CLAUDE.md והפרויקט, על האישורים הנדרשים ועל מצב הלמידה שבחרתי.
אל תצמצם את החקירה, המימוש או הבדיקות כדי לקצר את ההסבר.
אל תשנה קובצי הוראות ואל תתקין הפעלה קבועה.
אם אינך יכול לקרוא את הקובץ, אמור זאת ואל תטען שהפעלת אותו.
```

הפרומפט מבקש הפעלה בשיחה הנוכחית. הוא אינו מבטיח שהכלי יפעל לפי כל הוראה. בשיחה חדשה צריך למסור שוב את הקובץ והבקשה. כדי להפסיק, כתבו: ״הפסק להשתמש בסקיל לא לחפור בשיחה הזאת״. גם זו הוראה לכלי, לא הסרה של התקנה.

## מה לבדוק

בחרו בקשה שאתם באמת עובדים עליה. אחרי התשובה, בדקו: האם הבנתם מה קרה ולמה, מה עדיין לא נבדק, ומה הצעד הבא? האם נשמרו פרטים חשובים? שימו לב גם לעבודה עצמה, ולא רק לניסוח.

אפשר להשיב למייל של שלהבת עם הבקשה המקורית, מה רציתם להבין, מה הבנתם ומה נשאר לא ברור. צירוף התשובה הוא רשות; הסירו פרטים אישיים, סודות ומידע רגיש לפני שיתוף.
