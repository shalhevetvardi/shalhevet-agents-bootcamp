# vocabulary - בנק השפה המקצועית

המונחים שמפעילים את המודל. כשממלאים ממד בשלב 2, שולפים מכאן את המונח המדויק במקום לכתוב מעורפל. הכל באנגלית (זה נכנס לפרומפט).

---

## מצלמות ועדשות

שם מצלמה משנה את ה"DNA הוויזואלי" של התמונה:
- **GoPro** - תחושת אקשן אימרסיבית, עיוות.
- **Fujifilm** - מדע צבע אותנטי.
- **Disposable camera** - גולמי, נוסטלגי, פלאש.
- **Leica SL2 / Phase One XF** - מקצועי, חד, יוקרתי.

עדשות (המודל מחשב מהן עומק שדה ופרספקטיבה):
- **24mm wide-angle** - מדגיש קדמת פריים, עיוות אנכי לארכיטקטורה, סקייל.
- **35mm** - טבעי, דוקומנטרי.
- **85mm f/1.2 / f/1.8** - פורטרט, עומק שדה רדוד, בוקה קרמי.
- **100mm macro, 1:1 magnification** - פרטים, טקסטורה edge-to-edge.

פרמטרים: `f/1.8` (רדוד) עד `f/11` (עמוק), `ISO 100`, `sharp focus on eyes`.

## תאורה

- **Three-point softbox setup** - תאורה אחידה, טובה למוצר.
- **High-key commercial** - סופטבוקס גדול מלמעלה, כרטיסי החזר לבנים, אחיד ומחמיא.
- **Golden hour backlighting** - אור חם, צללים ארוכים, רומנטי.
- **Chiaroscuro** - ניגודיות גבוהה, חד, דרמטי.
- **Rembrandt lighting** - key ב-45°, משולש אור על הלחי המוצללת, צל עמוק.
- **Rim lighting** - קו אור שמפריד את הנושא מהרקע.
- טמפרטורת צבע: `3200K` (חם) / `5600K` (קר). אפשר לערבב (highlights חם, shadows קר).

## Color grading וסטוק פילם

- **1980s color film, slightly grainy** - נוסטלגי, גריטי.
- **Cinematic color grading, muted teal tones** - מודרני, מודי.
- **High saturation** - תוסס, פרסומי.
- **Medium-format analog film, pronounced grain** - אֶדִיטוֹריאלי יוקרתי.
- **Kodak Portra / Cinestill 800T** - סטוקים עם אופי צבע מוכר.

## סוגי צילום וזוויות

- Close-up / macro / extreme close-up
- Medium shot / medium-full shot
- Wide shot / establishing shot
- Low-angle (עוצמה) / high-angle (חולשה) / eye-level / aerial / bird's-eye
- Center-framed / rule-of-thirds / off-center

## מדיום וסגנון

- **Photoreal / hyper-realistic commercial** - צילום מסחרי.
- **Editorial / fashion magazine** - אופנה.
- **Watercolor** (soft bleeding edges, paper texture, gentle washes) - אקוורל.
- **3D render / Pixar-style / claymation** - תלת-ממד.
- **Line art / flat illustration / vector** - איור.
- **Pixel art / voxel** - פיקסל.
- **Oil painting / impressionist / Van Gogh-style** - ציור.
- **Cyberpunk / retro-futuristic / minimalist / brutalist** - כיווני עולם.
