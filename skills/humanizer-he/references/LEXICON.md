# Lexicon - רשימת Red-Flag לזיהוי מהיר

**קובץ זה הוא reference של `humanizer-he`.** נטען בזמן הסריקה הראשונית כדי לזהות דפוסים לפי מילים/ביטויים ספציפיים, בלי להיכנס לפרטי הכלל. אחרי שמזהים - פותחים את [PATTERNS.md](./PATTERNS.md) לטיפול המלא.

**מבנה:** מחולק לשלוש רמות:
1. **Always flag** - לסמן בכל register ללא הבחנה
2. **Register-dependent** - לסמן רק ב-P/C; תקין ב-F/A
3. **Register-sensitive** - לסמן רק ב-C; תקין ב-F/A/P

---

## 1. Always flag (בכל register)

### פעלים ופעולות מנופחים
- מהווה, מהוות, מהווים, מהוון
- להוות (בכל הצורות)
- הינו, הינה, הינם, הינן
- משמש, משמשת, משמשים, משמשות (כשאוגד-ריק, לא כשיש תפקיד אמיתי)
- מיישמת, מיישם, ליישם (במובן implements - לא במובן "מבצעת")
- מתאפיין, מתאפיינת, מתאפיינים
- מתבטא, מתבטאת, מתבטאים
- נמנה עם, נכלל בין

*דפוס מתאים: #1*

**⚠️ חשוב - אל תבלבל בין #1 ל-#3:**

- #1 = **פעלי אוגד** שמחליפים את "הוא/היא". דוגמאות: מהווה, משמש, מיישמת, הינו.
- #3 = **הפועל "לייצר"** במקום פועל ספציפי. דוגמאות: לייצר תוכן, לייצר חיבור.

"מיישמת" = implements = דפוס #1 (אוגד), **לא** דפוס #3.
"לייצר" = generate = דפוס #3, **לא** דפוס #1.

## 3. Register-sensitive (flag ב-C בלבד)

### מחברים רגילים שקיבלו גושפנקה ספרותית
גם בעברית מדוברת יומיומית - כל אלה נשמעים קצת רשמיים מדי לוואטסאפ:

- לפיכך
- לכן (תלוי, לעיתים טבעי)
- כתוצאה מכך
- כפי שצוין
- אמנם... אולם / אבל

**הערה:** אלה לא "AI-isms" אמיתיים, הם פשוט formal-leak במדובר. לסמן עם flag חלש, לא עם "לתקן!".

## 4. כללי זיהוי מורכבים (מעבר למילים)

אלה דפוסים שלא מזוהים על ידי מילה אחת, אלא על ידי מבנה או תדירות:

| כלל | איך מזהים | דפוס מתאים |
|------|-----------|-------------|
| שרשרת סמיכויות | 3+ שמות עצם רצופים ללא של/ל- | #11 |
| עודף "של" | 3+ "של" ב-8 מילים רצופות | #12 |
| ניסוח סביל | בניינים נפעל/פועל/הופעל + מציין עושה-פעולה | #16 |
| שלישיית X, Y ו-Z | דפוס enumeration מושלם ללא סיבה | #19 |
| מבנה "לא רק X אלא גם Y" | רלציה ספציפית של הפרכת-צפייה | #18 |
| כותרת+הד | כותרת ש-H2/H3 ואז שורה ראשונה חוזרת על הכותרת | #26 |
| רשימה עם bold header | `* **X:** Y` שבו Y הוא הכפלה של X | #28 |
| ברירת מחדל ז״י | "עליך / אתה יכול / אם אתה" עם הנחה של קהל זכר-יחיד | #21 |

## 5. סדר בדיקה מומלץ לסקיל

1. **ראשית** - Always flag (סעיף 1). אלה הכי קלים לזהות וחשובים לתפוס
2. **שנית** - לקבוע register (לפי REGISTER-GUIDE.md)
3. **שלישית** - Register-dependent (סעיף 2), רק אם register=P/C
4. **רביעית** - Register-sensitive (סעיף 3), רק אם register=C
5. **חמישית** - כללי זיהוי מורכבים (סעיף 4)
6. **שישית** - לעבור ל-PATTERNS.md לטיפול מלא בכל דפוס שזוהה
