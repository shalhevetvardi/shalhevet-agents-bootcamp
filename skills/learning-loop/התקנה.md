# 🛠️ התקנה - לולאת הלמידה

יש שלוש שכבות. **כל שכבה עומדת בפני עצמה.** התחל מ-1. רוצה יותר אוטומטי - עלה ל-2 ול-3.

---

## שכבה 1 - הכי פשוט (5 דקות, עובד לכולם)

מתאים גם בלי ידע טכני. שתי פעולות:

**א. התקן את הסקיל** (כמו כל סקיל-מתנה):
```bash
cp -r learning-loop ~/.claude/skills/
```

**ב. הוסף שורה ל-CLAUDE.md של הסוכן/הפרויקט** (אם אין קובץ - צור אותו בשורש התיקייה):

```markdown
## זיכרון
בתחילת כל שיחה - קרא את LEARNINGS.md (אם קיים) ואמץ את הלקחים.
בסוף משימה - אם למדת משהו, הוסף לקח אחד ל-LEARNINGS.md לפי הסקיל learning-loop.
```

זהו. מעכשיו אומרים לסוכן **"תלמד מהשיחה"** או **"/למד"** בסוף משימה, והוא מוסיף לקח. בתחילת שיחה הוא קורא את מה שלמד.

---

## שכבה 2 - הפעלה ידנית מסודרת (`/למד`)

הסקיל כבר עושה את זה אחרי שכבה 1. מילות ההפעלה:
- **"תלמד מהשיחה" / "/למד"** ← מהרהר ומוסיף לקח.
- **"מה למדת" / "טען לקחים"** ← קורא את ספר המשחקים.
- **"סדר את הלקחים"** ← תחזוקה: מאחד כפילויות, גוזם מה שלא עובד.

---

## שכבה 3 - טעינה אוטומטית (Claude Code, למתקדמים)

כדי שהסוכן יקרא את `LEARNINGS.md` **לבד** בכל פתיחת שיחה - בלי שתבקש:

1. פתח את `~/.claude/settings.json` (או את `settings.json` של הפרויקט).
2. העתק לתוכו את תוכן `hooks/hooks.json` שמצורף לסקיל (אם כבר יש לך מפתח `"hooks"` - מזג, אל תדרוס).
3. שמור, פתח שיחה חדשה. הסוכן יטען את הלקחים אוטומטית ב-SessionStart.

### למה רק טעינה אוטומטית - ולא גם כתיבה אוטומטית?

הכתיבה (ההרהור בסוף) נשארת בהפעלה ידנית (`/למד`) **בכוונה**, מסיבה אמיתית:

> **גוטצ'ה ידועה (race condition):** הוק מסוג `Stop` עלול לרוץ *לפני* שהשורה האחרונה של השיחה נכתבה לקובץ התמלול. כתיבה אוטומטית כזו עלולה לפספס בדיוק את מה שקרה בסוף. לכן הכתיבה הידנית (`/למד`) אמינה יותר - אתה מפעיל אותה כשהמשימה באמת הסתיימה.

מי שבכל זאת רוצה כתיבה אוטומטית - אפשר עם הוק `Stop` שמוסיף השהיה קצרה לפני קריאת התמלול. זה כבר טריטוריית מפתחים, לא חלק מהמתנה הבסיסית.

## איך יודעים שזה עובד

- פתח שיחה, בקש משהו, ובסוף אמור **"/למד"**. בדוק שנוצר/עודכן `LEARNINGS.md`.
- פתח שיחה חדשה ואמור **"מה למדת"** - הסוכן אמור לדקלם את הלקח.
- (שכבה 3) פתח שיחה חדשה בלי לבקש כלום - הסוכן אמור להזכיר שטען לקחים.
