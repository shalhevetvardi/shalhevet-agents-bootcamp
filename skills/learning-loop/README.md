# 📘 לולאת הלמידה - סוכן שמשתפר מעצמו

> הופכת כל סוכן Claude מסוכן ש"שוכח" אחרי כל שיחה - לסוכן שצובר ניסיון.
> נכנסת אצלכם כבר בשיעורי הבית של שיעור 1, יחד עם `session-close` שמפעיל אותה בסוף כל עבודה.

## מה זה עושה

ברירת המחדל של כל סוכן: כל שיחה מתחילה מאפס. לימדת אותו משהו? תיקנת אותו? בשיחה הבאה הכל נמחק.

הסקיל הזה נותן לסוכן **זיכרון חיצוני**: קובץ `LEARNINGS.md` שהוא קורא בתחילת שיחה ומוסיף אליו לקחים בסופה. הסוכן לא משתנה - **הזיכרון שלו** משתנה. כך הוא נהיה טוב יותר עם הזמן.

מבוסס על **ACE (Agentic Context Engineering)** - המסגרת המובילה (2025) לסוכנים שמשתפרים: עדכוני דלתא במקום שכתוב, ולקחים ספציפיים במקום כללים גנריים.

## ⚠️ שונה מ"קולט ידע" - שני מנגנונים, לא אחד

הסקיל הזה **כותב לקחים אוטומטית**, בלי לעצור ולבקש אישור - זה בכוונה, וזה כל הרעיון של ACE: מהירות וחיכוך אפס. זה **לא** כלל "קולט הידע" (אם יש לך אחד ב-CLAUDE.md האישי) שדורש הצעה מאושרת לפני שמשהו הופך לכלל קבוע. שני מנגנונים, לשתי מטרות שונות - אל תצפו שהם יתנהגו אותו דבר.

## קבצים בתיקייה

| קובץ | מה זה |
|------|-------|
| `SKILL.md` | המוח - איך הסוכן לומד, מתי, ובאיזה פורמט |
| `LEARNINGS.template.md` | תבנית ספר המשחקים (הסוכן יוצר ממנה את `LEARNINGS.md`) |
| `hooks/hooks.json` | הוק לטעינה אוטומטית ב-Claude Code (שכבה 3) |
| `התקנה.md` | מדריך התקנה - 3 שכבות, מהפשוט לאוטומטי |

## התקנה מהירה

```bash
cp -r learning-loop ~/.claude/skills/
```
ואז קרא את `התקנה.md`. בסוף משימה אמור **"/למד"** - והסוכן מתחיל לזכור.
